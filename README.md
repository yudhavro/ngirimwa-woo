# NgirimWA Woo

Plugin WordPress untuk mengirim notifikasi WhatsApp otomatis dari WooCommerce menggunakan NgirimWA.

## Persyaratan
- WordPress 6.0+
- WooCommerce 10.0+
- Koneksi internet untuk akses API

## Instalasi
1. Upload plugin ke direktori `/wp-content/plugins/`
2. Aktifkan plugin melalui menu 'Plugins' di WordPress
3. Buka WooCommerce > NgirimWA Woo untuk konfigurasi

## Konfigurasi
1. Dapatkan API Key dari [NgirimWA Dashboard](https://dash.ngirimwa.com)
2. Masukkan API Key di halaman pengaturan plugin
3. Konfigurasi template pesan untuk berbagai status pesanan

## Fitur
- Notifikasi WhatsApp otomatis untuk pesanan baru
- Dukungan multi-bahasa
- Kustomisasi template pesan
- Log aktivitas pengiriman pesan

## Dukungan
Untuk bantuan, hubungi [Dukungan NgirimWA](https://dash.ngirimwa.com)
